# MJ Rahman — Graphic Design Portfolio

A visual portfolio for Mohammad Jillur Rahman, a Vancouver-based graphic designer with 15+ years of experience across branding, marketing, print, and digital design.

Explore selected work in logo and product design, campaigns, social media, print collateral, events, and 3D rendering, alongside a profile, experience, and contact details.

## Preview

This is a static site with no build step. From the project folder, start a local server:

```bash
python -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000). Keep the `img/` folder beside `index.html`; the page loads its artwork from there. Google Fonts and GSAP animations are loaded from CDNs, so an internet connection is needed for those enhancements.
